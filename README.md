# PM Consulting Evidence

Selected, anonymized technical companion material for the case studies published
at [paulymurph.com/work](https://paulymurph.com/work).

This is a curated reading repository, not a production-code release. Files may
be cleaned extracts of prior implementation patterns, sanitized derivatives,
reconstructed architecture, or synthetic mockups. Customer identities,
infrastructure coordinates, operational records, commercial terms, and
proprietary identifiers have been removed or replaced.

## How to Read This Repository

Each file declares its evidence classification:

- `sanitized_derivative`: independently cleaned and generalized from private
  implementation evidence; not an exact production file.
- `reconstructed_from_context`: architecture recreated from retained design
  context where complete original implementation was unavailable.
- `synthetic_portfolio_example`: new mock data or contracts created only to
  illustrate the design safely.

These files demonstrate architecture and engineering judgment. They are not an
engagement archive and do not independently verify deployment, ownership,
production scale, commercial outcomes, or every claim on the associated pages.

## Disclosure Boundary

- No raw conversation exports or operational datasets are included.
- No credentials, tenant IDs, workspace IDs, hostnames, or private endpoints are included.
- Rates, thresholds, capacities, dates, and identifiers are synthetic or symbolic.
- Recovered implementation defects are corrected or called out rather than silently presented as production behavior.
- Private provenance mappings remain outside this repository.
