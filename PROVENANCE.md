# Evidence Provenance

## Classification Policy

| Classification | Meaning in this repository |
| --- | --- |
| `sanitized_derivative` | Rewritten from private recovered implementation or design evidence with names, values, infrastructure, and unsafe behavior removed |
| `reconstructed_from_context` | Recreated from documented architecture and retained design intent rather than recovered as a complete source file |
| `synthetic_portfolio_example` | Newly authored example containing no real operational data or production configuration |

Exact source and file-level mappings remain in a separate private recovery
workspace and are intentionally excluded from this repository and its history.

## Source Families

| Public evidence area | Treatment |
| --- | --- |
| BOM and processing time | Rewritten around neutral entities and configurable standards |
| Complexity tiers and rates | Commercial values replaced with synthetic examples |
| Labor and plan/actual | Corrected grain, additivity, and argument-position defects |
| Scheduling and routing | Rebuilt to show explicit constraints, audit records, and conservation |
| Fabric ingestion and Silver | Infrastructure and source taxonomy removed; failure modes made explicit |
| Freshness controls | Rebuilt as a timezone-aware SLA check |
| Gold SQL models | Physical schemas and proprietary rules generalized |
| Foundry/Fabric patterns | Converted to non-executable references because recovered SDK variants were unverified |
| Agent grounding and intent | Generalized into requirements and interface-design examples |

## Interpretation Limits

Private recovery establishes that related implementation patterns and design
discussions existed. This repository does not assert that every displayed file
was used in one engagement or deployed exactly as shown. Authorship, production
execution, and business outcomes remain separate portfolio claims.
